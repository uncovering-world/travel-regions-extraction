# Quality review — Q001

| Проверка из задания | Результат и граница проверки |
|---|---|
| country → region | Нет поля country и нет canonical verdict. |
| claim → control | Claim evidence отдельно; спорные coarse control descriptions имеют independent/UN либо qualified provenance. Shaksgam secondary corroboration ограничена. |
| administrative → operational boundary | Exact polygons не созданы; experiment selections явно обозначены. |
| permit → region | PAP/overlays не превращаются в итоговые регионы. |
| ordinary controls | C001–C006 присутствуют. |
| потенциальное расхождение profiles | C008/C009: independent admission при unknown P1; C013 и identity cases требуют model decisions. Доказанного P1=false/P2=true нет. |
| data vs model uncertainty | Раздельные разделы data-gaps.md; comparison blocked_by отдельно от model_questions. |
| open-world merge discipline | `may_merge` требует complete/equal hard signatures; отсутствие witness остаётся `separation_not_proven` или явным blocker outcome. |
| Q001 / Q006 routing | Q001 присутствует как общий identity question; Q006 ограничена disputed/occupied/international-status comparisons. |
| evaluator fixtures | 15 fixtures покрывают witness split, jurisdiction split, positive merge, missing data, undefined identity, source conflict, rule conflict, name/order invariance. |
| disputed CIP dates | Проверка 2026-09-11; исторические evidence dates сохранены. |
| Western Sahara precision | Нет точных polygons; status/zone/overlay отдельны. |
| blind model integrity | 12 требуемых пар; field structure и provenance links сохранены, имена/URL удалены. |

Автоматическая проверка проверяет структуру и согласованность, а не истинность права. Read-status, historical/qualified/provisional evidence нельзя повышать до verified по факту прохождения validator. Набор пригоден для тестов обработки неизвестности; полный текущий admissions atlas из него не следует.
